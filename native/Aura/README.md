# Aura — нативный музыкальный компаньон для macOS

**SwiftUI + AppKit + AVFoundation + Accelerate (vDSP) + WidgetKit + Security**  
Абсолютно нативное, легковесное и отзывчивое приложение для macOS. Без Electron, без веб-обёрток, без сторонних зависимостей. Требует macOS 14+ (Sonoma или новее), Swift 5.9+ и Xcode Command Line Tools.

---

## Архитектура проекта

## Ключевые возможности

### 1. Честная аппаратная аудио-реактивность (Apple Accelerate `vDSP` FFT)
- **Local FFT (Аппаратный DSP)**:
  - При воспроизведении локальных треков звук декодируется через `AVAudioEngine`.
  - На tap-шину микшера (`installTap`) поступают сырые блоки по 1024 float PCM-семплов.
  - Анализатор применяет окно Ханна (`vDSP_hann_window`) для предотвращения спектрального растекания и производит 1024-точечное быстрое преобразование Фурье через векторный движок Apple Accelerate.
  - Амплитудный спектр разбивается на **21 логарифмическую полосу эквалайзера** (20 Гц — 18 кГц) с мгновенной атакой и инерционным затуханием.
  - Детектор кика/бочки (`kickImpact`) анализирует всплески энергии в диапазоне суббаса (20–250 Гц), синхронизируя масштаб свечения и пульсацию ауры в такт музыке.
- **Spotify Cloud Sync**:
  - При воспроизведении из Spotify Aura обращается к аудио-анализу трека (Audio Features / Analysis API) и получает точные таймкоды долей, темп (BPM) и энергетику композиции.
- **Smart Beat-Grid**:
  - Для внешних плееров (Apple Music / офлайн Spotify) формируется адаптивная квантованная ритмическая сетка.
- **Прозрачный статус**:
  - Под эквалайзером и в настройках выводится стильный неоновый индикатор режима: 🟢 `Local FFT` (1024-pt FFT), 🔵 `Spotify Sync`, 🟣 `Smart Beat-Grid`.

### 2. Асинхронная автоматизация плееров (Zero Latency)
- **Фоновый `PlayerAutomationService` (Swift Actor)**:
  - Все вызовы AppleScript к Spotify и Apple Music вынесены за пределы главного потока с таймаутом выполнения 1.5 сек. Зависший плеер больше никогда не блокирует графический интерфейс.
- **Мгновенный отклик через `DistributedNotificationCenter`**:
  - Aura слушает системные события `com.spotify.client.PlaybackStateChanged` и `com.apple.Music.playerInfo`. При переключении трека или паузе статус обновляется с задержкой 0 мс, не дожидаясь таймера опроса.

### 3. Защита данных и сетевая безопасность
- **macOS Keychain**:
  - API-ключи, секреты и сессионные токены Last.fm сохраняются в системной связке ключей macOS (`kSecClassGenericPassword`, уровень доступности `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`). Полностью устранено небезопасное хранение в `UserDefaults`.
- **Строгий HTTPS**:
  - Из `Info.plist` исключен небезопасный флаг `NSAllowsArbitraryLoads`. Все сетевые запросы проходят исключительно по протоколу TLS/HTTPS.

### 4. Динамические обои с поддержкой нескольких мониторов
- При смене трека Aura плавно генерирует и устанавливает динамические обои рабочего стола на основе размытой палитры обложки.
- **Мультимониторность**: обои индивидуально рассчитываются под разрешение и соотношение сторон каждого активного экрана (`CGDirectDisplayID`).
- **Бережное сохранение**: пути к оригинальным обоям пользователя фиксируются для каждого дисплея отдельно и автоматически восстанавливаются при отключении функции или выходе из приложения.
- **Энергоэффективность**: рендеринг Core Image выполняется асинхронно в фоновом потоке с дебаунсом (150 мс) и отменой устаревших задач. При блокировке экрана (`com.apple.screenIsLocked`) рендеринг приостанавливается.

### 5. Оверлей рабочего стола (Desktop Overlay)
- Безрамочное полупрозрачное окно-виджет, размещаемое на уровне рабочего стола прямо под иконками Finder (`kCGDesktopWindowLevel`). Показывает текущий трек, обложку и атмосферную подсветку, не мешая работе.

### 6. Строка меню (Menu Bar Extra) и Мини-плеер (Always-on-Top)
- **Menu Bar**: иконка со звуковой волной в верхней строке macOS открывает компактный всплывающий плеер с управлением и прогрессом трека.
- **Мини-плеер**: плавающее окно с эффектом стекла (`.floating`, Always on Top) для удобного управления фоновой музыкой во время работы.

### 7. Интеграция с Last.fm
- Полноценная поддержка официального протокола Last.fm 2.0:
  - Авторизация через браузер по безопасному токену.
  - Автоматическая отправка Now Playing в начале трека.
  - Честный скробблинг по правилам Last.fm (не менее 30 сек и 50% длительности).
  - Быстрая отметка «Любимый трек» (Love / Unlove) с сохранением состояния.

### 8. Виджет Notification Center (WidgetKit)
- Расширение `AuraWidget` для боковой панели Центра уведомлений macOS.
- Атомарный экспорт состояния плеера и обложки через App Support / Caches.
- Мгновенная перезагрузка таймлайна виджета через `WidgetCenter.shared.reloadTimelines`.

## Горячие клавиши

| Сочетание клавиш | Действие |
| :--- | :--- |
| **`Space`** | Воспроизведение / Пауза |
| **`Cmd + Right`** | Следующий трек |
| **`Cmd + Left`** | Предыдущий трек |
| **`Cmd + O`** | Открыть локальные аудиофайлы (MP3, M4A, WAV, AIFF, FLAC) |
| **`Cmd + Shift + M`** | Переключить режим плавающего мини-плеера (Always on Top) |
| **`Ctrl + Cmd + F`** | Полноэкранный режим погружения (CoverView) |
| **`Esc`** | Выход из полноэкранного режима |

## Сборка и установка на Mac

### Требования:
- Mac на процессоре Apple Silicon (M1/M2/M3/M4, arm64).
- macOS 14.0 Sonoma или новее.
- Установленные Xcode Command Line Tools (`xcode-select --install`).

### Сборка из исходников:

1. Перейдите в каталог `native/Aura`:
   ```bash
   cd native/Aura
   ```

2. Запустите скрипт сборки:
   ```bash
   ./build.sh
   ```

3. Скрипт выполнит:
   - Компиляцию Swift пакета в release-конфигурации (`swift build -c release`).
   - Сборку бандла расширения `AuraWidget.appex`.
   - Формирование бандла `dist/Aura.app` со всеми метаданными и правами доступа Apple Events.
   - Подписание ad-hoc сертификатом.
   - Упаковку в дистрибутивный образ **`dist/Aura.dmg`**.

4. Откройте `dist/Aura.dmg` и перетащите **Aura** в папку **«Программы»** (`/Applications`).

> [!IMPORTANT]
> Для корректной выдачи системных разрешений на управление плеерами (Системные настройки → Конфиденциальность и безопасность → Автоматизация) приложение обязательно должно запускаться из папки `/Applications`.
